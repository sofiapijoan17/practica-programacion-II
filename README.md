# Análisis de movimiento de aviones 

En este repositorio/projecto de RStudio encontrarás 2 archivos:

* `01_lectura.qmd` donde el objetivo es leer y preparar los datos para el análisis.
* `02_analisis.qmd` donde intentarás responder algunas preguntas usado los datos disponibles. 

El objetivo es descubrir y aprender a usar funciones nuevas que te permitiran extender el uso de los paquetes de tidyverse. 

**Te recomendamos hacer 1 commit luego de resolver cada consigna para asegurarte de que guardas todo.**
